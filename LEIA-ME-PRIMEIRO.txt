MEU COFRE 1.0.0 - KDBX 4.1

ARQUIVOS PARA GITHUB PAGES
1. Faça backup .mcvault da v0.2.2 antes de atualizar.
2. Envie TODOS os arquivos deste pacote para a RAIZ do MESMO repositorio.
3. Nao mude o endereco GitHub Pages.
4. Aguarde o deploy e abra o PWA com internet.
5. Aceite o banner de atualizacao.
6. Desbloqueie o cofre antigo e use Seguranca > Migracao obrigatoria.
7. Guarde o .mcvault antigo, o novo .kdbx e a .key de recuperacao.
8. Teste YubiKey e recuperacao antes de apagar qualquer backup.

IMPORTANTE
- Esta release grava KDBX 4.1 AES-256-CBC + AES-KDF.
- Argon2d/Argon2id de KDBX externos sao recusados nesta versao.
- A .key de recuperacao tem 32 bytes. Guarde fora do iPhone.
- Para modo Senha + YubiKey, a recuperacao exige senha + .key.
- Use conta GitHub bem protegida; comprometer a origem web compromete um PWA.
- Nao houve auditoria externa independente.
