MEU COFRE 1.1.0 - KDBX 4.1 + LEITOR VERACRYPT

ATUALIZAR NO GITHUB PAGES
1. Faça backup do seu .kdbx antes da atualização.
2. Envie TODOS os arquivos deste pacote para a RAIZ do MESMO repositório.
3. Não mude o endereço GitHub Pages.
4. Aguarde o deploy e abra o PWA com internet.
5. Aceite o banner de atualização.

NOVA ABA VOLUMES
- seleciona um arquivo-container VeraCrypt local;
- senha, PIM e keyfiles não são enviados a servidor;
- suporte atual: AES-256-XTS + PBKDF2 SHA-512/SHA-256;
- FAT12/16/32 e exFAT;
- somente leitura; arquivos escolhidos são exportados em texto claro;
- YubiKey PIV não é acessada diretamente. O backup de 64 bytes do objeto 5FC103 pode ser escolhido como keyfile comum.

TESTE PRIMEIRO COM CONTAINER DESCARTÁVEL. NÃO USE O ÚNICO EXEMPLAR DE DADOS CRÍTICOS.
